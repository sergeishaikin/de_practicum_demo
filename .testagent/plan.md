## Verification

`pytest tests/ -v` → all green; `pytest --cov=medallion --cov=writer --cov=common` →
report coverage vs 80% target. Any failing test = research finding to document, not
silently changed behavior.

### Result (2026-08-07)

- `pytest tests/` → **37 passed**.
- Coverage: `ops.py` 96%, `iceberg_medallion.py` 90%, `iceberg_writer.py` 88%,
  **TOTAL 90%** (target 80% met).
- Uncovered lines are all integration/orchestration: `get_catalog`/`get_fs`/
  `read_batch`/`ensure_table` (network), crash-sim `os._exit` branches,
  `main()`/`__main__` guards, `Metrics.close()` exception swallow.
- Findings recorded:
  1. `build_silver` raises `ArrowNotImplementedError` when a hashed column is
     entirely null (all-null `event_time`). Runtime consequence: an empty/all-null
     bronze scan crashes the medallion cycle (caught by `main()`'s error handler).
  2. Prior-context suspicion of a duplicated `source text not null` DDL in
     `common/ops.py` is **not real** — exactly one occurrence; earlier reading was
     a tool-output artifact.
  3. Writer main-loop behavior pinned by fakes: commit-conflict retry backs off
     `sleep(1)`, reloads table, succeeds on attempt 2; exhausted conflicts raise
     into the error path which cleans `pending` and marks files done only if the
     load id is found committed.
