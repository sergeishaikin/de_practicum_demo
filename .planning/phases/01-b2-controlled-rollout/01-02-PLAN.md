<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Operator environment -> medallion container | Rollout variables select the active data path. |
| Medallion -> Bronze/Silver/Gold Iceberg tables | B2 commits Silver and legacy projection feeds Gold. |
| Medallion -> PostgreSQL metrics | Operational counters and failure statuses become durable evidence. |
| Runtime logs/metrics -> canary receipt | Safety decisions depend on captured observations. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | Gold source selection | mitigate | Assert b2/legacy/1 in the container and reject any persisted-Silver or shadow-disabled state. |
| T-01-02 | Tampering | B2 Silver/progress state | mitigate | Reuse existing M3 progress and B2 commit paths; rollback changes configuration only and never resets state. |
| T-01-03 | Denial of Service | Shadow failure or stuck progress | mitigate | Monitor metrics/logs, stop the cycle, and restore legacy/legacy/0 on the first failure. |
| T-01-SC | Tampering | Package installation | accept | No package installation is planned; an unexpected install blocks the rollout. |
</threat_model>
